# Typing-Speed-Test
## ⌨️ Typing Speed Test

A simple and interactive Typing Speed Test web application that helps users measure their typing speed, accuracy, and performance in real time. The app provides a paragraph to type, tracks mistakes, and calculates WPM (Words Per Minute). Typing tests typically compute speed using characters or words per minute and track accuracy and errors during the session.

### 🚀 Features
- Real-time typing speed calculation (WPM)
- Accuracy tracking
- Mistake highlighting
- Timer-based typing test
- Restart / Try again option
- Clean and responsive UI
- Dynamic paragraph generation
- Live statistics display

### 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- DOM Manipulation
